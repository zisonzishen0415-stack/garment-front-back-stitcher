# PS 样品照片拼接工具

桌面端离线工具，将服装样品正反面照片自动裁切、拼接为 1:1 正方形结果图。

## 核心设计

### 联合轮廓匹配法（v11）

最关键的设计决策：**利用正反面外轮廓高度相似这一先验约束，联合处理配对图片**。

#### 为什么需要联合处理

独立处理每张图时，rembg 会引入三类噪声：

| 噪声源 | 成因 | 独立处理的后果 |
|--------|------|---------------|
| **金属支架杆** | 画面底部的细长金属杆，rembg 可能识别为前景 | 衣服 bbox 向下延伸过多 → 品类误判、裁切过大 |
| **白色人台** | 人台露出的白色部分可能被 rembg 当作衣服 | bbox 边界不准确 |
| **与背景色相近的衣服** | 浅色/白色衣服与渐变灰背景接近 | 轮廓不完整 |

**关键洞察**：这些噪声不会对称地同时出现在正反面两张图中。

#### 方法

1. 对配对的两张图分别获取 rembg mask
2. 计算垂直宽度分布（逐行扫描前景的左右边界）
3. 逐行比较宽度比 — 宽度比 > 1.35 的行视为噪声，排除
4. 取最大连续共识区间作为衣服真实区域
5. 在共识区域内确定每张图的 bbox

```
正面 mask          反面 mask
  |                  |
逐行宽度            逐行宽度
  \                /
   逐行宽度比 < 1.35?
        |
  共识区间 → 裁切参数
```

### 裁切策略

- **高度驱动**：以衣服高度决定裁切尺寸，品类自动分级
- **内侧锚定**：衣服内侧边缘到中心拼缝的距离按品类设定（短款 7% / 中款 6% / 长款 5% / 全长 4%）
- **逐级降级**：边界冲突时 margin → 半 margin → 0 → 缩小裁切
- **等比缩放**：拼合以较矮裁切为准，scale down 不 scale up

### EXIF 方向处理

必须调用 `PIL.ImageOps.exif_transpose()` 处理原始照片的 EXIF 旋转标签，否则所有定位计算都基于错误的方向。

## 技术栈

- **rembg** (u2net) — AI 分割，仅用于定位（不用于抠图）
- **Pillow** — 图像裁切、缩放、拼接
- **NumPy** — 数值计算
- **customtkinter** — 桌面 GUI
- 完全离线运行，无需网络

## 目录结构

```
PS/
├── main.py              # 入口
├── processor.py          # 核心处理逻辑（联合轮廓匹配 + 裁切拼接）
├── gui.py                # customtkinter 界面
├── requirements.txt      # 依赖
├── .gitignore
└── README.md
```

## 运行

```bash
pip install -r requirements.txt
python main.py
```

GUI 操作流程：选择输入文件夹 → 扫描配对 → 选择输出文件夹 → 开始处理。

## 输入要求

- 文件名按字母序排列，两两配对
- 支持 JPG / PNG / BMP / TIFF 格式
- 棚拍照片，模特居中，背景为渐变灰
