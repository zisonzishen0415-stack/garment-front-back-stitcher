# Garment Front-Back Stitcher

桌面端离线工具，将服装样品正反面照片 AI 检测 + 人工审核后裁切拼接为 1:1 正方形结果图。

## 功能概览

| 功能 | 说明 |
|------|------|
| **AI 自动检测** | rembg + 联合轮廓匹配，自动定位正反面商品区域 |
| **杆子/人台过滤** | 智能识别并裁剪底部金属支架、白色人台等摄影噪声 |
| **审核编辑 GUI** | 流式处理 + 实时预览 + bbox 拖拽 + 角度微调 |
| **液化修图** | PS 风格前推变形，可对拼接结果手动微调细节 |
| **批量导出** | 一键导出全部拼接结果或逐对导出 |

## 快速开始

```bash
pip install -r requirements.txt
python reviewer.py
```

1. **浏览**选择原图文件夹 → 点击 **AI 处理**
2. AI 逐对处理，第一对完成自动加载
3. **左窗**实时预览拼接结果（灰色半透明参考网格）
4. **右窗**拖拽绿框调整范围，点击角度旋钮微调
5. 满意后按 **S** 导出当前对，或点击 **全部导出**

## 核心技术：联合轮廓匹配（v11.1）

### 问题

独立处理每张图时，rembg 会将三类摄影噪声误识别为商品：

| 噪声 | 表现 | 影响 |
|------|------|------|
| 金属支架杆 | 画面底部细杆 | bbox 向下延伸过多 |
| 白色人台/假人 | 人台肤色被当衣服 | bbox 边界不准 |
| 浅色衣服+灰色背景 | 衣服与背景相近 | 轮廓不完整 |

### 解法

**正反面商品轮廓高度对称**——利用这一先验约束联合处理配对的两人张图：

1. 对配对图分别跑 rembg 获取 mask
2. 逐行扫描计算垂直宽度分布
3. 逐行比较正反面宽度比，> 1.35 的行视为不对称噪声
4. 取最大连续共识区间作为商品真实区域
5. **杆子/人台底部裁剪**：mask 宽度占比 < 12% 的持续窄区识别为杆子，从商品范围中切除

验证结果：32 张含杆子图全部准确裁剪，0 误剪 0 漏剪。

## 技术栈

- **rembg** (u2net.onnx) — AI 分割，仅用于定位 bbox
- **Pillow** — 图像裁切、旋转、拼接、EXIF 处理
- **NumPy / SciPy** — 数值计算、液化像素重映射
- **customtkinter** — 桌面 GUI
- 完全离线运行，无需网络

## 输入要求

- 文件名按字典序排列，两两配对（奇数位正面，偶数位反面）
- 支持 JPG / PNG / BMP / TIFF
- 棚拍照片，模特居中，渐变灰背景
- 建议图像分辨率 ≤ 4080px 以保证 AI 处理速度
